# Orchestrator Synthesis Anti-Speculation

**Status:** Open
**Type:** Backlog
**Source:** Observed in 8-model run

## Summary
Stop estimated/proxy figures outranking measured data; align Executive Summary "best" framing with the ranked recommendations.

## Detail
During synthesis, the model appears to be prioritizing estimated or proxy data over actual measured data. This causes:
- Estimated figures to rank above actual measurements in recommendations
- Executive Summary using "best" framing that doesn't match the actual ranked recommendations
- Misalignment between evidence and conclusions

## Suspected fix
Add explicit instructions to prioritize measured data and enforce consistency between ranking and summary framing.
